# Frequency Generator

A phone-ready tone generator: sine, square, triangle and sawtooth waves, log-scale frequency control from 1 Hz to 20 kHz, binaural beats, frequency sweeps, an OBE build-up mode, and a sleep timer.

**OBE build-up** pulses a carrier tone (isochronic, optionally binaural) starting slowly and accelerating until the pulses melt into a solid steady tone. It is for relaxation only; there is no proof it induces out-of-body experiences.

Open `index.html` over HTTPS (or localhost). On iPhone: Safari → Share → Add to Home Screen. If you hear nothing, turn the Silent switch off or use headphones.

This is not a medical device. Start at a low volume.

No build step. Static files only.
